# Инструкция по публикации AsemPro в RuStore

## Шаг 1: Регистрация разработчика

1. Перейди на https://console.rustore.ru
2. Нажми "Зарегистрироваться"
3. Выбери тип аккаунта:
   - **Физическое лицо** - нужен паспорт РФ
   - **Юридическое лицо** - нужны реквизиты организации
   - **ИП** - нужны данные ИП
4. Заполни все поля, подтверди email

## Шаг 2: Создание приложения

1. В консоли RuStore нажми "Создать приложение"
2. Заполни:
   - **Название**: AsemPro - Водитель
   - **Пакет**: com.taxopark.driver
   - **Категория**: Бизнес
   - **Возрастной рейтинг**: 0+

## Шаг 3: Загрузка APK

1. Скачай APK из GitHub Releases:
   https://github.com/Koloda55SA/-/releases
2. В консоли RuStore загрузи APK файл
3. Укажи версию: 1.0.0

## Шаг 4: Описание и медиа

1. **Краткое описание**: 
   "Приложение для водителей таксопарка: путевые листы, управление сменами"

2. **Полное описание**:
   Скопируй из файла metadata.md

3. **Скриншоты**: 
   Сделай скриншоты экранов приложения (минимум 2):
   - Экран входа
   - Главный экран с профилем
   - Экран генерации путевого листа

4. **Иконка**: 512x512 px, PNG

## Шаг 5: Политика конфиденциальности

URL: https://taxopark-admin.pages.dev/privacy.html

## Шаг 6: Декларация данных

В разделе "Безопасность данных" укажи:
- **Собираемые данные**: Имя, email, телефон, документы водителя
- **Цель сбора**: Выполнение основных функций приложения
- **Передача третьим лицам**: Нет
- **Шифрование**: Да (Firebase TLS)
- **Удаление данных**: По запросу пользователя

## Шаг 7: Отправка на модерацию

1. Проверь все поля
2. Нажми "Отправить на модерацию"
3. Модерация обычно занимает 1-3 рабочих дня

## Требования RuStore к APK:
- ✅ targetSdkVersion >= 30 (у нас 34)
- ✅ minSdkVersion >= 21 (у нас 21)
- ✅ Подпись APK (debug signing для начала, позже заменить на release)
- ✅ Политика конфиденциальности
- ✅ Возрастной рейтинг

## Примечание о подписи

Для production-релиза в RuStore рекомендуется создать release keystore:
```bash
keytool -genkey -v -keystore asempro-release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias asempro
```
И обновить build.gradle для подписи release-сборки.
