# AsemPro - Метаданные для RuStore

## Название приложения
AsemPro - Водитель

## Краткое описание (80 символов)
Приложение для водителей таксопарка: путевые листы, управление сменами

## Полное описание
AsemPro - мобильное приложение для водителей таксопарка. Позволяет водителям быстро и удобно получать электронные путевые листы, соответствующие требованиям Приказа Минтранса России №390 от 28.09.2022 г.

Основные возможности:
- Авторизация водителя по данным, предоставленным администратором
- Просмотр личного профиля и данных транспортного средства
- Генерация путевого листа в формате PDF
- Указание показаний одометра, времени медосмотра и техконтроля
- История выданных путевых листов
- Печать или сохранение путевого листа

Приложение предназначено для внутреннего использования водителями таксопарка и работает совместно с административной панелью управления.
