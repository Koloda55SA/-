Политика конфиденциальности

Приложение AsemPro для водителей таксопарка

1. Общие положения

Настоящая Политика конфиденциальности определяет порядок обработки и защиты персональных данных пользователей мобильного приложения "AsemPro" (далее - Приложение).

Используя Приложение, вы соглашаетесь с условиями данной Политики конфиденциальности.

2. Какие данные мы собираем

Приложение собирает и обрабатывает следующие данные:

  • ФИО водителя
  • Контактный телефон
  • Адрес электронной почты (для авторизации)
  • Данные водительского удостоверения
  • Данные транспортного средства (марка, гос. номер)
  • СНИЛС, ИНН водителя
  • Данные путевых листов (дата, время, показания одометра)

3. Цели обработки данных

Персональные данные обрабатываются в следующих целях:

  • Авторизация и идентификация пользователя в Приложении
  • Формирование и выдача путевых листов в соответствии с требованиями Минтранса РФ
  • Ведение учета рабочего времени водителей
  • Обеспечение безопасности дорожного движения
  • Выполнение требований действующего законодательства РФ

4. Хранение и защита данных

Данные хранятся на серверах Firebase (Google Cloud Platform) с применением следующих мер защиты:

  • Шифрование данных при передаче (TLS/SSL)
  • Шифрование данных при хранении
  • Правила безопасности Firestore для контроля доступа
  • Аутентификация пользователей через Firebase Authentication

5. Передача данных третьим лицам

Мы не передаем персональные данные третьим лицам, за исключением случаев:

  • Предусмотренных действующим законодательством РФ
  • По запросу уполномоченных государственных органов

6. Права пользователя

Пользователь имеет право:

  • Получить информацию об обрабатываемых персональных данных
  • Требовать уточнения, блокирования или уничтожения персональных данных
  • Отозвать согласие на обработку персональных данных

Для реализации указанных прав обратитесь к администратору таксопарка.

7. Использование файлов cookie и аналитики

Приложение использует Firebase Analytics для сбора анонимной статистики использования. Данные аналитики не содержат персональной информации и используются исключительно для улучшения работы Приложения.

8. Изменение политики

Мы оставляем за собой право вносить изменения в настоящую Политику конфиденциальности. Актуальная версия всегда доступна по данному адресу.
